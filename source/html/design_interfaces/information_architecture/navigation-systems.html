Navigation Systems

Navigation turns an invisible structure into something people can move through. On every page it should answer: where am I, where can I go, how do I get back?

Designing interfaces By Alessandro Campanari

Wayfinding on a screen

People rarely arrive through the home page: they land on a deep page from a search engine or a shared link. Every page must therefore orient them on its own.

Steve Krug's trunk test checks this: imagine being dropped on a random page and try to answer a few questions at a glance. Here it is applied to this page.

The trunk test, applied to this page
Question Answer on this page
What site is this? "HCI" in the top-left corner
What page am I on? The title "Navigation Systems"
What are the main sections? The Topics menu in the top bar
Where am I? The breadcrumb below

Three layers of navigation

Global

The same on every page, it leads to the main sections. Here: the top bar.

Local

Leads to the pages next to the current one. Here: the previous and next links.

Contextual

Links inside the text, like this one to Part 2.

Breadcrumbs

A breadcrumb shows where the current page sits in the hierarchy and lets people go up a level with one click. This is the breadcrumb for this page:

  1. Home
  2. Designing interfaces
  3. Information architecture
  4. Navigation systems
Do

Show the position in the hierarchy, from the home page to the current page.

Avoid

Using breadcrumbs as the only navigation, or on a site with just one or two levels.

Menus: show it or hide it?

Common menu patterns
Pattern Strength Weakness
Visible top bar Always in sight Room for few items
Dropdown menu Shows two levels at once Hover-only versions fail on touch
Hidden menu (hamburger) Saves space Out of sight, out of mind

Hiding the navigation behind an icon makes people use it less. The Topics menu of this website stays visible and shows topics and subtopics as two clear levels.

Designing for the wrong turn

People will take wrong paths. Good navigation makes them cheap to recover from:

  • Keep the global navigation on every page.
  • Never break the browser's Back button.
  • Make "page not found" pages useful, with links to the main sections.
  • Link related pages to each other.
