Organizing and Labeling Content

How to group content the way people think, check it with real users and give every group a clear name.

Designing interfaces By Alessandro Campanari

Every grouping is a decision

Imagine designing the website of a university library: opening hours, the catalogue, room booking, printing, loans. There is no single correct way to sort them, and each choice makes some things easier to find than others.

Scheme
The criterion used to form groups: by topic, by date, by task...
Structure
How the groups are connected to each other.
Label
The name of a group or a page.

Choosing a scheme

Exact schemes have one obvious place for every item. Ambiguous schemes need judgement, but they help people who are exploring.

exact

Alphabetical

Databases A to Z. Useful only if you know the name.

exact

Chronological

Events by date. Works when time is the main question.

ambiguous

Topic

Research guides by subject. Natural for exploring.

ambiguous

Task

Borrow, Book a room, Print. Matches what people came to do.

Sites can combine schemes, but each menu level should use only one:

Mixed schemes

Students, Books and journals, Borrow and renew, Lugano campus.

One scheme (tasks)

Find, Borrow, Study spaces, Get help, Visit.

Choosing a structure

Hierarchy

Categories inside categories, as in most menus.

Metadata

Properties like format or year, combined as filters.

Links

Related pages pointing to each other.

Sometimes a page belongs in two places. A guide on citing sources fits both "Get help" and "Thesis support", so it can appear in both branches:

  • Library
    • Get help
      • Citing sources
    • Thesis support
      • Citing sources

Tree testing

Users look for items in a text-only menu, showing where the structure fails.

Labels: naming what is inside

A label is a promise: people click it because they expect to find something behind it.

Rewriting labels for the library website
Before After Why
Interlibrary loan Get a book from another library Use the users' words
Services Printing Be specific
Loans Borrow Use one term everywhere
More info Late return fees Make sense on its own
A quick check for every label
  • Would a first-year student use this word?
  • Could it be confused with the label next to it?
  • Is it the same in menus, headings and links?
