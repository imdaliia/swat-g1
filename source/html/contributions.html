Name Role Contributions
Giulio Berti Group leader CSS leader

Developed the shared theme, article template and practical examples that gave the groups a common starting point for building their pages.

  • Project coordination: helped define the five topics and organize work between the groups
  • Shared pages and author guidance: developed the homepage, theme demo page and article template; documented how to create an article, apply topic colours and reuse shared components through examples and copyable markup
  • Visual design and reusable components:
    • established the shared colour palette, topic accents and status colours
    • implemented the page layout, including the header, article sheet, top bar navigation and footer
    • defined typography for headings, links, lead paragraphs, code and quotations
    • built reusable grids, boxes, notes, pills and buttons, together with the base table style
    • styled images and captions to support both article illustrations and homepage cards
  • Responsive layout and accessibility: adapted grids, typography and page spacing for tablet and phone screens; implemented a keyboard-visible skip link and kept animated hover effects conditional on the user's reduced-motion preference
  • Fonts and image assets: bundled the regular and italic Atkinson fonts with their open-source licence, added homepage images from the shared Canva/FIGMA sketch, and added the SVG background pattern
  • Presentation: added and revised the midway presentation slides
Lorenzo Felix Group leader CSS leader

Contributed from the first site prototype through shared styling, navigation and integration, helping turn separately developed pages into a consistent website.

  • Project coordination: helped define the five topics and organize work between the groups, supported coordination, communication and technical problem-solving, and connected the content structure with the shared site design
  • Site foundations and examples: built the initial homepage, test-page prototype and shared CSS draft; simplified and documented the stylesheet; updated the homepage, theme demo page and article template with feature examples and contribution credits
  • Visual design and responsive behaviour:
    • added dark mode that follows the device appearance, with adapted text, surface and topic colours
    • created liquid glass surfaces for the top bar, footer and boxes, with brighter HDR reflections on supported displays in light mode
    • added the animated light sweep across images on hover, respecting the user's reduced-motion preference
    • centered incomplete grid rows while preserving the responsive layout
    • expanded table styling with striped rows, hover and focus highlights, distinct footers, rounded corners and sideways scrolling for wide tables
  • Navigation and keyboard access: built the compact top bar and Topics dropdown with nested subtopics; rolled out consistent navigation across pages; adjusted relative paths and previous/next links; added contributions-page links, visible focus indicators and fixes that let keyboard users reach submenu links
  • Favicon and site maintenance: added the transparent SVG favicon and rolled it out across the site; wrote and documented three Node.js scripts to sync the homepage’s main navigation while preserving each page’s Previous/Next buttons, and update favicon links with the correct relative paths. Added a separate updater to set the Previous/Next destinations from the site reading order
  • Page integration: integrated the gesture-based interfaces page and its image, and updated Future Interfaces overview content and Input/output Devices index links
  • Review and repairs: fixed broken image paths, folder-name mismatches, source citation IDs, duplicate source entries, HTML syntax and grammar; checked Inclusive Design pages locally in Chrome and Safari and corrected heading hierarchy and text errors
  • Presentation: added the introductory slides and PDF, correcting names and duplicate entries
