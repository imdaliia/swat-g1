Start a page

Every page links only style.css. The path depends on how deep your file is: count the folders between your page and the project root.

Paths from your page to the shared files
Your page Stylesheet Home
source/html/sample-article.html ../css/style.css index.html
source/html/web_accessibility/page.html ../../css/style.css ../index.html
source/html/design_failures/dark_patterns/page.html ../../../css/style.css ../../index.html

Images work the same way, e.g. ../../images/web_accessibility/photo.jpg. The fonts are loaded by the stylesheet itself: nothing to add.

Rules

  1. Every page has <meta name="author" content="Name Surname"> (it is graded) and passes the W3C validator.
  2. Write plain HTML elements. Use a class only when this page tells you to.
  3. Put your topic class on <body>: the whole page takes the topic colour.
  4. Your topic stylesheet may add classes with a prefix (wa-, df-...) but never restyle a shared selector like p or .callout.
  5. No colours, fonts or sizes written by hand: use the variables, e.g. var(--accent).
  6. Headings go in order (h1, then h2, then h3), and there is one h1 per page.

Callouts

Boxes that stand out from the text. Start with a short title that says what kind of box it is: colour alone does not carry meaning.

Did you know?

Plain callout, in the topic colour.

Good practice

Give both options the same visual weight.

Be careful

Colour alone is not enough to show an error.

Avoid

Never disable zoom on mobile.

Markup 
<div class="callout tip">   <!-- or: callout, callout warning, callout danger -->
  <strong>Good practice</strong>
  <p>Text of the callout.</p>
</div>

Tables

Wrap every table in .table-wrap: on phones it scrolls sideways instead of breaking the page. Always give it a <caption> and use <th scope> for headers. Add .num to cells with numbers.

Confirmshaming vs honest wording
Element Confirmshaming Honest Clicks on "no"
Decline text "No, I hate saving money" "No thanks" 12%
Buttons One big, one tiny Same size 31%
Status Dark pattern Fair -

Numbers are example data.

Markup 
<div class="table-wrap">
  <table>
    <caption>What the table shows</caption>
    <thead>
      <tr>
        <th scope="col">Element</th>
        <th scope="col" class="num">Clicks</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">Decline text</th>
        <td class="num">12%</td>
      </tr>
    </tbody>
  </table>
</div>

Images

Every image needs an alt that describes it (or alt="" if it is only decoration). Images below the first screen get loading="lazy". By default images are cropped to 16:9.

Caption chip

Caption below, with source

Use it in articles, where captions are longer. Add .natural for diagrams and screenshots that must not be cropped.

Collapsible blocks

For FAQs, solutions to exercises or details most readers can skip. Works without JavaScript.

What is a dark pattern?

An interface designed to push users into doing something they did not mean to do.

Is every pop-up a dark pattern?

No. It becomes one when it hides, shames or tricks.

Markup 
<details>
  <summary>Question</summary>
  <p>Answer.</p>
</details>

Accessibility checklist

Try it now: reload the page and press Tab.

  • Skip link: the first Tab shows "Skip to content". Keep it as the first element of <body>.
  • Focus ring: every link and button shows an outline in the accent colour. Never remove it.
  • Current page: mark it with aria-current="page", the style follows.
  • Reduced motion: hover animations switch off when the system asks for it.
  • Links: say where they go. "Read the WCAG guidelines", not "click here".
