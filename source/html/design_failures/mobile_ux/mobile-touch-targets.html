Bad Mobile Touch Targets

When buttons and links are too small to tap comfortably.

By Emilie Bui 5 min read

Introduction

Touch targets are the areas of a screen that users interact with by tapping their fingers. They include buttons, links, icons, checkboxes and other interactive elements. On mobile devices, these elements need to be large enough to select comfortably and accurately.

Unlike a computer mouse, a finger does not point to a screen with the same precision. This means that small buttons or links placed too close together can easily cause mistakes. A user may tap the wrong option, open an unwanted page or activate an action they did not intend to select.

Touch target size is therefore an important part of mobile usability and digital accessibility. A good interface should make every important action easy to find and comfortable to use.

1. EverEye: An Example of Poor Touch Targets

The EverEye cookie consent interface provides an example of how touch targets can make a website more difficult to use. The option to continue without accepting cookies appears as a small, light-grey link, while the other choices are displayed as much larger buttons.

This difference in size and visibility makes the refusal option harder to notice and select, especially on a small screen. Users may have to concentrate more carefully to tap the correct link. They may even select one of the larger buttons by mistake.

A well-designed consent interface should give users clear and accessible ways to make their choices. Accepting and refusing should both be easy to understand and select. Important choices should not become difficult simply because their buttons or links are smaller.

2. Why Are Small Touch Targets a Problem?

Small touch targets can create several problems during everyday mobile browsing. Even if a website looks visually attractive, it may still be difficult to interact with when its buttons and links are not designed for touch.

  • Accidental taps: users may select a neighbouring button or link instead of the option they intended to choose.
  • Difficult navigation: small interactive elements require more precision, making navigation slower and less comfortable.
  • Accessibility barriers: people with motor difficulties, reduced dexterity or limited control of their movements may struggle to use small targets.
  • User frustration: repeatedly tapping the wrong element can make simple tasks tiring and unpleasant.

These difficulties are particularly noticeable when several links or buttons are positioned close together. For example, a row of small icons may be easy to use with a mouse but much harder to select with a finger. Users should not need several attempts to complete a basic action.

The problem is not limited to people with permanent disabilities. Someone using a phone while walking, holding it with one hand or dealing with a temporary hand injury may also find small targets difficult to use. Accessible design benefits a wider range of users.

3. Recommended Touch Target Sizes

Several design guidelines provide recommendations for the size of interactive elements. These recommendations help designers create interfaces that are easier to use on touchscreens.

Apple

44 × 44 pt

Apple's Human Interface Guidelines recommend touch targets of at least 44 × 44 points to make controls easier to interact with. [1]

Material Design

48 × 48 dp

Google's Material Design guidance uses a 48 × 48 dp touch target as a recommended size for interactive elements. [2]

WCAG 2.2

24 × 24 CSS px

WCAG 2.2 includes a minimum target size criterion, with specific exceptions. [3]

These measurements use different units, so they should not be compared as if they were exactly the same. Points, density-independent pixels and CSS pixels are different measurement systems.

The WCAG 2.2 minimum target size criterion also includes exceptions. For example, the spacing between targets and the availability of an equivalent control can affect whether a particular target meets the criterion. Therefore, designers should consider both the size of an element and the space around it. [3]

4. Size Is Not the Only Important Factor

Making buttons larger is important, but good touch target design involves more than dimensions. The position, spacing and appearance of interactive elements also influence how easily users can select them.

Spacing between elements

Buttons and links should have enough space between them. When two interactive elements are placed very close together, users may accidentally activate the wrong one. Sufficient spacing helps reduce this risk and makes an interface feel less crowded.

Clear visual appearance

Interactive elements should be easy to recognise. Buttons need clear labels, and links should be visually distinguishable from ordinary text. Colour and contrast can also help users identify important actions.

Consistent design

Similar actions should have a consistent appearance and interaction area throughout a website. If buttons change size or position unexpectedly, users may need more time to understand how to interact with the page.

5. How Can Touch Targets Be Improved?

Designers can prevent many touch target problems by following a few practical principles when creating mobile interfaces.

  • Use sufficiently large targets: make buttons, links and icons comfortable to select with a finger.
  • Leave enough spacing: separate interactive elements to reduce accidental taps.
  • Make actions visible: use clear labels, appropriate contrast and recognisable button styles.
  • Keep choices equally accessible: important options should not be hidden behind tiny links or difficult controls.
  • Test on real devices: check that buttons and links are comfortable to use on different screen sizes.

Testing is particularly useful because an interface that works well on a desktop computer may not work as well on a smartphone. Designers should test interactions using touchscreens and consider different users and situations.

Conclusion

Small mobile touch targets may seem like a minor design detail, but they can have a significant impact on usability and accessibility. Buttons and links that are difficult to tap can cause mistakes, slow down navigation and prevent some users from completing simple tasks comfortably.

Following established guidelines, providing enough spacing and making interactive elements clearly visible can help prevent these problems. Ultimately, a good mobile interface should make every action easy to find and easy to select.
